# Спецификация из Revit

Собирает спецификацию оборудования, изделий и материалов по форме ГОСТ 21.110
из выгрузки Revit и заодно проверяет модель на незаполненные параметры.

## Зачем
- Одинаковые позиции из разных участков модели складываются в одну строку.
- Строки без наименования, единицы измерения или количества не теряются молча:
  скрипт выводит список, что и где поправить в модели.
- Результат сразу открывается в Excel двойным щелчком, без мастера импорта.

## Как выгрузить из Revit
1. Создайте вид «Спецификация/Количества» по нужной категории, например воздуховоды или оборудование.
2. Добавьте поля с такими именами: Система, Наименование, Обозначение, Код, Изготовитель,
   Ед. изм., Количество, Масса ед., кг, Примечание. Если у вас поля называются иначе,
   переименуйте заголовки столбцов в самой спецификации Revit.
3. Снимите галочку «Подробно показывать каждый экземпляр» не обязательно: скрипт сложит строки сам.
4. Меню Файл, затем Экспорт, затем Отчёты, затем Спецификация. Сохраните файл `.txt`.

## Как запустить

```
python3 спецификация.py выгрузка_revit.txt
```

Появится файл `спецификация_ГОСТ.csv` и отчёт об ошибках на экране.

## Пример
В `выгрузка_revit.txt` лежит учебная выгрузка по системам П1, В1 и Т1.
В ней специально оставлены две ошибки: решётка без единицы измерения
и строка без наименования. Скрипт их находит.

## Что можно настроить в начале скрипта
- `REQUIRED` — какие параметры обязательны.
- `KEY` — по каким параметрам позиции считаются одинаковыми.
- `GOST_COLUMNS` — заголовки итоговой таблицы.
