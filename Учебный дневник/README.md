# Учебный дневник

Мой личный репозиторий для учёбы: конспекты, дедлайны и цели в одном месте.
Всё написано обычным текстом в формате Markdown, программировать не нужно.

## Что здесь лежит
- `цели.md` — что я хочу достичь в этом семестре.
- `дедлайны.md` — таблица сдач и экзаменов.
- `конспекты/` — по одному файлу на каждую лекцию или тему.

## Как пользоваться
1. Перед занятием: создать ветку, например `git checkout -b lecture-2026-10-20`.
2. На занятии: скопировать `конспекты/_шаблон.md` под новым именем и заполнить.
3. После занятия: сохранить и отправить.

```
git add .
git commit -m "Конспект: тема лекции"
git push -u origin lecture-2026-10-20
```

4. Открыть pull request и слить его самому. Это мой личный репозиторий,
   проверяющего здесь нет.

## Правила имён
Файлы конспектов называю по шаблону `ГГГГ-ММ-ДД предмет тема.md`,
например `2026-10-20 экономика спрос и предложение.md`.
