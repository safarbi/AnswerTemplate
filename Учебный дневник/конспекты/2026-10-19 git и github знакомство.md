# Знакомство с Git и GitHub

- Дата: 2026-10-19
- Предмет: Информатика

## Главные идеи
- Git помнит все версии файлов на моём компьютере.
- GitHub хранит эти версии в интернете и позволяет работать вместе.
- Основная ветка `main` должна оставаться чистой. Всё новое делается в отдельной ветке.

## Термины
- **Репозиторий** — папка проекта вместе с историей.
- **Коммит** — одно сохранение с подписью.
- **Ветка** — параллельная копия для экспериментов.
- **Push** — отправить коммиты на GitHub.
- **Pull request** — просьба добавить мои изменения в основную версию.
