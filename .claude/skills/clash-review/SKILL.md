# Разбор коллизий

Порядок работы:

1. Прочитать `Разбор коллизий/правила.csv` и `Разбор коллизий/исправления.csv`.
   Исправления важнее правил.
2. Уточнить, что за файл прислали. Для Navisworks нужен экспорт с вкладки «Тесты»,
   если результат должен импортироваться обратно. Отчёт с вкладки «Отчёт» обратно не импортируется.
3. Запустить разбор:
   `cd "Разбор коллизий" && python3 коллизии.py <путь к отчёту>`
4. Просмотреть все коллизии с пометками «Настоящая» и «Проверить вручную».
   По каждой коротко написать, что делать: какой раздел правит и как.
5. Если исправление в журнале встречается два раза и больше, предложить новое правило.
   Новое правило ставить выше общих правил.
6. Итог показать таблицей: сколько коллизий каждого вида и что требует решения инженера.

Ограничения:
- Реальные отчёты по объектам не коммитить: репозиторий публичный.
- Окончательное решение по настоящим коллизиям принимает инженер, скрипт делает первый разбор.
