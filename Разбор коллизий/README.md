# Разбор коллизий

Проходит по всем коллизиям из отчёта и помечает каждую:

| Пометка | Что значит |
|---|---|
| Настоящая | Нужно исправлять модель |
| Допустимая | Можно закрыть, причина указана |
| Задание на отверстие | Сеть проходит через стену или перекрытие, нужен проём или гильза |
| Проверить вручную | Правило сомневается, решение за инженером |
| Дубликат | Та же пара элементов уже есть в другом тесте |

Итог — таблица `коллизии_разбор.csv`, которая открывается в Excel двойным щелчком.

## Какие отчёты понимает
- **Navisworks Clash Detective.** Вкладка «Отчёт», формат «XML». Даёт глубину пересечения.
- **Revit, «Проверка на пересечения».** Кнопка «Экспорт», файл HTML. Глубины в нём нет,
  поэтому правила с ограничением по глубине к нему не применяются.

## Как запустить

```
python3 коллизии.py отчёт.xml
python3 коллизии.py отчёт.html
```

## Правила
Правила лежат в `правила.csv`. Откройте его в Excel и правьте под свои нормы и BEP проекта.
- Правила проверяются сверху вниз, срабатывает первое подходящее. Важные ставьте выше.
- В полях «Элемент содержит» можно писать несколько слов через `|`, это значит «или».
- Пустое поле подходит к любому элементу.
- «Глубина до, мм» ограничивает правило мелкими пересечениями.
- Порядок A и B не важен, скрипт проверяет обе стороны.
- Если ни одно правило не подошло, коллизия считается настоящей.

Правила в файле учебные. Допуски и решения по проёмам согласуйте с ГИП и смежниками.

## Как научить Claude своим решениям
Claude не запоминает разговоры, но читает файлы репозитория.
1. Когда скрипт ошибся, добавьте строку в `исправления.csv`:
   какая коллизия, что поставил скрипт, что правильно и почему.
2. Сделайте коммит с понятной подписью, например
   «Исправления: изоляция о потолок допустима».
3. В следующей сессии попросите Claude «учти исправления».
   Он прочитает файл и превратит повторяющиеся исправления в новые правила.

Так ваш опыт копится в репозитории, а история коммитов показывает,
когда и почему изменилось каждое решение.

## Важно
Скрипт делает первый разбор по правилам и экономит время на очевидных случаях.
Окончательное решение по каждой настоящей коллизии остаётся за инженером.
