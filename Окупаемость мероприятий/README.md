# Окупаемость мероприятий

Калькулятор для первого продукта: аудит климата и энергии здания,
затем мероприятия с окупаемостью.

Цифры в `мероприятия.csv` учебные, а не данные реального объекта.
Замените их на свои, например по семейному объекту.

## Как пользоваться
1. Откройте `мероприятия.csv` в Excel или блокноте и впишите свои мероприятия.
2. Запустите расчёт со своей ставкой дисконтирования, например 16%:

```
python3 расчет.py мероприятия.csv 16
```

3. Результат появится на экране и в файле `результат.csv`, который открывается в Excel.

## Что означают показатели
- **Простая окупаемость.** Затраты, делённые на годовую экономию. Быстро, но не учитывает, что рубль через 5 лет стоит меньше сегодняшнего.
- **Дисконтированная окупаемость.** То же, но каждый будущий рубль экономии пересчитан в сегодняшние деньги по ставке.
- **NPV.** Сколько мероприятие принесёт сверх затрат в сегодняшних рублях. Больше нуля значит выгодно.
- **IRR.** Доходность мероприятия в процентах годовых. Если она выше ставки, проект выгоден.

## Как это связано с планом
- Подготовка к комитету: финмодель с NPV, IRR и окупаемостью.
- Ниша ОВ, автоматика и энергоэффективность: какие мероприятия окупаются.
- Довод для собственника: автоматика как экономия, выраженная в деньгах.
