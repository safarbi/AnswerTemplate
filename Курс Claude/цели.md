# Цели обучения и маршрут

Темп: один помодоро в день, как в чек-листе. Сроки примерные.

## Цель 1. Автоматизировать свою рутину
Часть A. Claude Code до уверенного уровня: уроки 5–7. Около 2 недель.
Часть B. Своя рутина в скиллы. Около 4 недель.
1. Выписать 10 повторяющихся рабочих задач и время на каждую.
2. Выбрать три самых дорогих по времени.
3. На каждую сделать скилл, при необходимости скрипт и хук.
4. Карта хранения: что лежит в GitHub, что на ПК, что в Notion.

## Цель 2. ИИ для ведения бизнеса
Решение от 6 ноября 2026: в схемах для бизнеса в России модели не Anthropic,
например GigaChat или YandexGPT. Claude используется только вне России.
Навыки курса переносятся: скиллы, MCP и n8n работают с любой моделью.

Часть C. Около 6 недель.
1. API языковых моделей: как программа обращается к модели без чата. Практика на GigaChat или YandexGPT.
2. n8n: схемы «событие, затем действие», например письмо пришло, Claude разобрал, задача создана.
3. MCP: подключить Claude к своим сервисам.
4. Человек в контуре: Claude готовит документы и проводки, человек проверяет и подписывает.
Ограничения, которые нужно учесть до запуска:
- Бухгалтерия и налоги: ответственность на бухгалтере и руководителе, Claude готовит черновики.
- Персональные данные: 152-ФЗ ограничивает передачу за рубеж, это важно для клиентов и госслужбы.
- Доступность Claude и способ оплаты API в России проверить заранее.

## Цель 3. Масштабировать: ИИ-интегратор для бизнеса
Часть D. Около 3 месяцев параллельно с C.
Нужно:
- Python: основной язык. Скрипты, API, обработка таблиц.
- SQL: базовый уровень. Данные бизнеса живут в базах.
- HTTP, API и JSON: как сервисы общаются между собой.
- LLM-инженерия: промпты, работа с инструментами, MCP, поиск по документам, проверка качества ответов.
- n8n или аналог для схем без кода.
- Git и Docker на базовом уровне.
Не нужно для этой роли: высшая математика и обучение собственных нейросетей.
